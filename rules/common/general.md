# General Coding Rules

1. Read before you write — understand existing code before modifying
2. Minimal changes — don't refactor unrelated code in the same change
3. No dead code — if it's unused, delete it (git remembers)
4. No magic numbers — use named constants
5. Handle errors — never catch and ignore
6. Test your changes — verify before declaring done
7. Clear naming — code should read like prose
8. One function, one job — if it does two things, split it
9. Early returns — reduce nesting
10. Comments explain why, not what
