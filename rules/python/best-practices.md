# Python Best Practices

1. Type hints on all function signatures
2. Use dataclasses or Pydantic for structured data
3. Context managers for resource cleanup (with statement)
4. List comprehensions over map/filter when readable
5. Use pathlib over os.path
6. Use f-strings over format() or %
7. Generator expressions for large sequences
8. ABC for abstract base classes
9. Use logging module, not print()
10. Virtual environments always
